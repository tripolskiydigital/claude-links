# Claude Links — полоса ссылок для Claude Desktop

[English](../README.md) · **Русский**

Мод для **вкладки Code в Claude Desktop**: ссылки, с которыми вы работаете, — в один клик, в полосе над промптом.

```
[Проект] Сессия   ■ Kan   ■ figma.com/file/x   ■ Длинное назв…   +      [Последние] [Все · 6]
```

- **Закреплённые ссылки с favicon**, до 4 на панели. Ссылку можно закрепить за **проектом** (её видят все сессии этой папки) или только за **этой сессией**; маленький переключатель **Проект / Сессия** слева выбирает, какой набор показывать.
- **Коротко и аккуратно**: имя занимает не больше четверти места под ссылки; обрезанное показывается целиком (с URL) при наведении. Ссылка без названия показывается как URL без `https://` и `www.`.
- **+** — одна строка: название, ссылка, Проект / Сессия, Отмена, Сохранить. Без названия ссылка получает заголовок своей страницы.
- **Последние** — при наведении над кнопкой появляется список 10 последних ссылок сессии с колонками **Проект** и **Сессия**: 📌 закрепляет ссылку там, ✓ — уже закреплена (нажатие открепляет), ✎ — переименовать закреплённую.
- **Все** — боковая панель (кнопка подсвечена, пока панель открыта) со всеми закреплёнными ссылками проекта и сессии: поиск, сортировка каждого списка по названию или по ссылке (А→Я, повторное нажатие — Я→А), перетаскивание за ⠿ (на полосе — первые 4 из каждого списка), переименование (✎), открепление (✕); при наведении на ссылку — полный адрес.
- **Перетаскивание и на самой полосе** — за ⠿ перед каждой ссылкой.
- **Говорит на вашем языке**: English, Deutsch, Français, Italiano, Español, Українська, Русский — по языку Claude Desktop; иначе английский.

Работает на **модах** Claude Code (плагины из function hooks) и не патчит приложение. Полосу над промптом мод делит с другими: то, что рисуют плагины под ним (например, [Claude Tabs](https://github.com/tripolskiydigital/claude-tabs)), остаётся, а строка ссылок — под ним.

## Установка

```bash
claude plugin marketplace add tripolskiydigital/claude-links
```

```bash
claude plugin install links-bar@claude-links
```

Затем новая сессия (или `/reload-plugins`).

## Что мод читает, пишет и запускает

- **Читает** транскрипт текущей сессии (`$.session.messages`): то, что писали вы и Claude, и ссылки, с которыми вызывались инструменты (WebFetch, переход в браузере). Вывод инструментов не сканируется. Ещё — поле `locale` из `~/Library/Application Support/Claude/config.json` через `grep`, остальное содержимое файла мод не видит.
- **Пишет** только в собственное хранилище плагина: закреплённые ссылки (`project:<папка>`, `session:<id>`), положение переключателя и кэш favicon (`favicon:<host>`, data URI до 24 КБ). Favicon сначала скачивается во временную папку.
- **Запускает** `open <url>` — открыть ссылку в браузере по умолчанию, и `curl` — скачать страницу закреплённой или последней ссылки (из её `<head>` берутся заголовок и объявленные иконки), эти иконки, затем `<сайт>/favicon.ico`. Если у публичного сайта его нет, мод спрашивает сервис favicon Google (`https://www.google.com/s2/favicons?domain=<host>`), то есть имя хоста уходит в Google. Локальные и частные адреса (localhost, `.local`, `.test`, частные IP) туда не отправляются.
